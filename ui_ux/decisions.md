# UI/UX Decisions

- **D1 — Phrase-first landscape workspace.** The four measures occupy the primary canvas, with controls in a secondary rail or bottom sheet, so reading notation is never displaced by setup. No prior question.
- **D2 — Four measures remain together.** The first release presents all measures in one non-scrolling phrase strip; it never turns the result into a rolling staff. No prior question.
- **D3 — Conventional, transposition-aware engraving.** The notation renderer receives semantic events and uses a SMuFL music font, correct rhythmic values, rests, beams, barlines, ties, accidentals, time signature, clef, and chord symbols; noteheads are never positioned from raw screen coordinates. No prior question.
- **D4 — Theme architecture separates semantic from palette tokens.** Light and dark modes swap semantic color values without changing component classes, leaving room for future themes. No prior question.
- **D5 — Fade-only phrase replacement.** Regeneration crossfades rendered phrase content after successful generation, while the staff frame stays stable to preserve reading position. No prior question.
- **D6 — Full-width phrase-first workspace.** The score occupies the complete primary row and receives maximum available width for distant reading. Controls follow it as a vertically scrolling, reoriented section rather than taking a desktop side rail. No prior question.
- **D7 — Warm music-desk visual direction.** Retain the warm paper, graphite, and brass identity for light mode, with its dark ink counterpart for dark mode; revise the workspace hierarchy to make the score still more dominant. Closes Q1.
- **D8 — Landscape-only mobile and tablet experience.** The first-release workspace is supported in landscape orientation on mobile and tablet devices; desktop receives the full-width layout when width is sufficient. Closes Q3.
- **D9 — Pitch-class selection and spelling.** Every pitch class is selectable. Use sharp spellings by default, but use flat spellings when the selected key or mode convention requires them. The default tonal context is C Ionian. No prior question.
- **D10 — Confirmed initial presets.** The neutral preset uses static harmonic motion, quarter-note density, straight syncopation, sparse rests, arch contour, and middle register. The jazz preset uses eighth-note density, occasional offbeats, conversational space, wandering contour, and varying register. No prior question.
- **D11 — Arpeggio chaos levels.** `Predictable` traces chord tones in an orderly ascending or descending direction; `Varied` permits slight inversions and reordering; `Chaotic` permits the strongest reordering within the profile, contour, range, and resolution constraints. No prior question.
- **D12 — Display and theme defaults.** First load displays B-flat notation. The initial theme follows the operating-system preference, with a manual light/dark override available. No prior question.
- **D13 — Mode catalogue.** Every chromatic tonal center is selectable. The selectable collections are major, minor, and all seven church modes: Ionian, Dorian, Phrygian, Lydian, Mixolydian, Aeolian, and Locrian. Closes Q4.
- **D14 — C instrument profile.** The C profile represents a MIDI keyboard rather than a C-melody saxophone. Its playable generation range and register windows were subsequently settled by D17. Closes Q10.
- **D15 — C keyboard active range.** The first-release C/MIDI-keyboard profile uses concert MIDI 48 through 72 inclusive, corresponding to C3 through C5. Its register windows were subsequently settled by D17. No prior question.
- **D16 — Jazz preset harmonic motion.** Jazz applies gentle diatonic harmonic motion while retaining its diatonic harmonic plan; its bounded chromatic approaches and enclosures do not create altered harmony. Closes Q7.
- **D17 — Declarative profile range and window policies.** C MIDI keyboard uses 48-72 with Low 48-60, Middle 54-66, High 60-72; B-flat tenor uses 46-70 with Low 46-58, Middle 52-64, High 58-70; E-flat alto uses 51-75 with Low 51-63, Middle 57-69, High 63-75. `Varying` deterministically selects one feasible whole-phrase fixed window. Closes Q8.
- **D18 — Independent notation conventions.** Concert, B-flat tenor, and E-flat alto are display-only conventions rendered in treble G2 clef. Their written transforms are respectively unison, major ninth, and major sixth, and never change source events or generator policy. Closes Q9.
- **D19 — Profile-switch retain or regenerate.** Retain unchanged concert events only when they fit the new active range and current resolved whole-phrase register window; otherwise keep controls, select a fresh seed, and regenerate the complete phrase without transposing source events. Closes Q11.
- **D20 — Phone-landscape two-system fallback (signed off 2026-09-24).** Below `bp-tablet-landscape` (64rem), the score first attempts one staff system with all four measures; if that does not fit at the legibility floor, it is engraved as two staff systems of two measures each (bars 1-2 on the first system, bars 3-4 on the second) within the same staff area, with clef and key signature repeated on the second system and the 4/4 time signature shown only on the first. All four measure regions stay visibly equal in width in both layouts, and the two systems' measure columns stay aligned. At `bp-tablet-landscape` and above, the prior rule is unchanged: exactly one staff system or the notation-error state. If two systems also cannot fit at the legibility floor, the notation-error state applies. Notation is still never horizontally scrolled, clipped, split into more than two systems, or shrunk below the legibility floor, and the score's height still follows its content. See `screens/phrase-workspace/handoff.md` (Notation Contract, Responsive Behavior) and `screens/phrase-workspace/intent.md`. No prior question.
