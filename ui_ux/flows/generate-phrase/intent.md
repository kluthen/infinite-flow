# Generate Phrase Intent

The player needs one complete musical thought, not four piecemeal surprises. The flow therefore makes generation a whole-phrase act. Any control change updates the pending musical direction but leaves the visible phrase intact until the player explicitly requests a replacement.

The workspace opens with a ready-to-generate empty staff when no result exists. Once a result exists, the same prominent action says `Regenerate phrase`, making the scope of replacement explicit. The action is deliberately near the score header rather than buried in controls: the player looks at the phrase, decides whether to seek another idea, and acts there.

The notation mode is a display control adjacent to the score. Concert, B-flat tenor, and E-flat alto notation all render in treble G2 clef. The manual theme override sits with this reading context and changes only the presentation palette. Changing either control never creates a generation request or changes the phrase, control values, seed, selected profile, or result data; notation mode alone redraws the written score. Controls follow the score in a vertically reached section: a compact horizontal group layout on wide displays and a stacked layout on mobile landscape. This gives all four measures the full available width without a horizontal scroll.

Instrument profile is a separate foundation choice from the neutral or jazz musical preset. The player selects the declarative C MIDI keyboard profile (concert MIDI 48-72; Low 48-60, Middle 54-66, High 60-72), B-flat tenor saxophone profile (46-70; Low 46-58, Middle 52-64, High 58-70), or E-flat alto saxophone profile (51-75; Low 51-63, Middle 57-69, High 63-75). A profile description makes the active range and three available whole-phrase windows inspectable without asking the player to reason from MIDI values during ordinary generation. `Varying` is a register choice, not a fourth window: the seeded planner selects one feasible Low, Middle, or High window for the whole phrase and does not switch it between measures or notes.

Switching profile is intentionally decisive because it can make a visible phrase unplayable. The workspace validates the unchanged concert events against both the newly selected active range and the current whole-phrase register window. For `Varying`, it deterministically resolves a candidate new-profile window using the existing seed before validation. When every event fits, the score redraws in the current notation mode. Otherwise the controls remain intact, a fresh seed is chosen, and the complete phrase regenerates under the new profile; source events are never transposed to force a fit.

The phrase is shown only after generation has produced a valid, complete result. During regeneration, the current phrase remains readable; the action becomes unavailable only long enough to prevent accidental duplicate requests. The next score replaces it as a cohesive unit rather than measure by measure. If generation fails, the prior valid score stays visible with a retry beside the action. If notation fails after valid phrase data exists, the score region instead becomes a notation-error panel with retry; it does not pretend letter names are a score.
