# Generate Phrase Intent

The player needs one complete musical thought, not four piecemeal surprises. The flow therefore makes generation a whole-phrase act. Any control change updates the pending musical direction but leaves the visible phrase intact until the player explicitly requests a replacement.

The workspace opens with a ready-to-generate empty staff when no result exists. Once a result exists, the same prominent action says `Regenerate phrase`, making the scope of replacement explicit. The action is deliberately near the score header rather than buried in controls: the player looks at the phrase, decides whether to seek another idea, and acts there.

The score always reads in the current instrument profile's own written pitch. There is no separate notation-display control and no Concert override: every instrument profile still renders in treble G2 clef, and only that profile's own fixed transposition (none for the C MIDI keyboard, a major ninth for the B-flat tenor saxophone, a major sixth for the E-flat alto saxophone) changes what is written. The manual theme override is the one remaining control adjacent to the score, and it changes only the presentation palette; changing it never creates a generation request or changes the phrase, control values, seed, selected profile, or result data. Controls follow the score in a vertically reached section: a compact horizontal group layout on wide displays and a stacked layout on mobile landscape. This gives all four measures the full available width without a horizontal scroll.

The tonal-context control — written key and collection — is read and set in the selected instrument profile's own written pitch, not in concert pitch: the player picks the key the way it is written for their instrument. Selecting C Ionian on the B-flat tenor saxophone profile shows an empty key signature and sounds a concert B-flat Ionian; on the C MIDI keyboard, written and concert pitch are identical. The control's label always shows the written selection; request construction, not the player, converts it to the concert tonal context the generator receives.

Instrument profile is a separate foundation choice from the neutral or jazz musical preset. The player selects the declarative C MIDI keyboard profile (concert MIDI 48-72; Low 48-60, Middle 54-66, High 60-72), B-flat tenor saxophone profile (46-70; Low 46-58, Middle 52-64, High 58-70), or E-flat alto saxophone profile (51-75; Low 51-63, Middle 57-69, High 63-75). A profile description makes the active range and three available whole-phrase windows inspectable without asking the player to reason from MIDI values during ordinary generation. `Varying` is a register choice, not a fourth window: the seeded planner selects one feasible Low, Middle, or High window for the whole phrase and does not switch it between measures or notes.

Switching profile is intentionally decisive: it keeps the written key and collection but always replaces the phrase. When a phrase is shown, the switch never validates the old phrase against the new active range and never retains or transposes it — it keeps every other control, takes a fresh seed, and regenerates the complete four-measure phrase under the new profile immediately. The one exception is a rhythm-control combination (note density, syncopation, silence density) that is already unsupported at the moment of the switch: the switch still applies and the new profile stays selected, but the phrase is cleared to the empty workspace instead of regenerating, and the unsupported-rhythm notice stays visible explaining why. With no phrase shown yet, the switch only changes the selected profile; nothing generates.

The phrase is shown only after generation has produced a valid, complete result. During regeneration, the current phrase remains readable; the action becomes unavailable only long enough to prevent accidental duplicate requests. The next score replaces it as a cohesive unit rather than measure by measure. If generation fails, the prior valid score stays visible with a retry beside the action. If notation fails after valid phrase data exists, the score region instead becomes a notation-error panel with retry; it does not pretend letter names are a score.
