# Phrase Workspace Review Mockups

- `phrase-workspace-light.svg` shows the proposed warm paper, graphite, and brass light theme.
- `phrase-workspace-dark.svg` shows the same hierarchy with dark ink, parchment notation, and muted brass.
- `phrase-workspace.html` is the interactive HTML/CSS review prototype. It imports `../ui_common.css`; use the `Light / dark` control to inspect both themes.

The mockups are visual review artifacts for the desktop landscape composition. They demonstrate hierarchy and theme behavior, not final music engraving or a functional application. The implementation must use the semantic notation contract in `../screens/phrase-workspace/handoff.md` rather than reproduce the illustrative notes.
