# Phrase Workspace Intent

The score is deliberately the focal point. A player should be able to sight-read the phrase without searching for where bar three begins or which chord governs a note. Four visibly equal measure regions, unbroken staff continuity, strong barlines, and chord symbols placed above their harmonic entry give the phrase its form at a glance.

The header gives only essential reading context: selected display mode, meter, tempo, and the whole-phrase action. It omits generator internals, seed data, and a performance interpretation because these do not help a player read the proposal. The selected tonal context and instrument profile appear in the control summary rather than competing with the printed chord symbols. The profile summary exposes the active range and whole-phrase register windows as explanatory metadata; it never changes the independently selected notation mode.

The score fills the first content row on every landscape target. Controls follow it in the vertical reading order, so a player can read the staff from a distance before scrolling to shape a replacement. Wide displays orient control groups horizontally across the page; landscape phones stack them into a compact scrollable section. Character controls sit in a disclosed section to keep the first interaction light without hiding a required control permanently.

The header takes only the space necessary for brand, notation context, theme override, and the whole-phrase action. The screen must not shrink notation to accommodate UI chrome. When available space is constrained, control content moves below the score before the score uses a smaller engraving scale. The defined landscape targets are a product constraint; portrait mobile and tablet views receive a rotate-device message instead of an illegible rearrangement, while desktop remains usable when it has sufficient width. A valid phrase can survive a profile switch only if its unchanged concert events fit the new active range and current resolved whole-phrase register window. The UI otherwise makes the regenerated replacement clear through the normal stable-frame loading and fade sequence rather than presenting a silent pitch transposition.
