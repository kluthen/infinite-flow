# Leap Recovery

## INTENT
Make larger melodic leaps recover in a playable, directional way.

## THE RULE / LOGIC
Larger leaps respect the selected leapiness and register, then recover by an opposite-direction step or short contrary motion. Consecutive leaps form a recognizable arpeggio instead of arbitrary zig-zags.

## TECHNICAL INTERFACE
Leapiness and register controls constrain melodic interval selection.

## EXPECTATION
A phrase with larger leaps shows the required recovery, and consecutive leaps read as an arpeggio rather than an arbitrary zig-zag.
