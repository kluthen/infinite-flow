# Jam Has One Embellishments Level for All Seven Figures

## INTENT
Keep Jam's set small while letting the player choose how decorated the melody is.

## THE RULE / LOGIC
In Jam mode one Embellishments level, Off, Rarely, Often or Very often, applies to all seven embellishment figures at once, each level meaning for every figure what it means for one figure in session mode. Seven separate levels would turn Jam's small set back into a generator to tune.

## TECHNICAL INTERFACE
One four-position Embellishments control among Jam's settings.

## EXPECTATION
- Every phrase of a Jam is generated with all seven figures at Jam's one Embellishments level.
