# Practice Session Controller

## INTENT
Own the one practice session the workspace runs at a time and drive it on the audio clock, from the Start click to the session's end.

## THE RULE / LOGIC
The workspace also builds the practice session controller, which owns the one session the workspace runs at a time. Its module, with the measurement of phrase 1's staff fixed parts, loads as its own chunk on a createSessionController call the app root makes once at setup; until it has loaded no session can start, and a controller that arrives after the app is torn down is disposed of at once. Its three session options (adaptive tempo, vary settings, tension across phrases) enter at its creation with the player's saved choices, loaded before the first draw. The controller judges the start conditions from the Idle state, the window's shape, whether a session is running and whether the review mode shows (a session's review or the session list), and exposes the first condition that blocks a start. The controller's load also loads the session runner (the engine and its failure ladder) through the workspace session's runner loader, so the runner is never in the entry chunk. From a session's start on, everything is driven by the audio clock, through an injected wake-up timer: the count-in display, the count-in's end, each phrase starting to sound and the engine's deadlines; every runner output is recorded in the session history, a phrase starting to sound at its scheduled start on the audio transport rather than at the engine's time, which may already have passed it when the wake-up fired. The player's saves are held from an accepted start and released when the session is torn down, at any end or when a start is undone part-way, so a setting changed during a session is saved when it ends. The fit check the runner is given judges each look-ahead phrase, with the intent of the attempt being checked, against the held staff layout and the current window's height budget, and the staff shows the session as the rolling display.

## TECHNICAL INTERFACE
The workspace session also exposes createSessionController(), which loads the controller's chunk and returns a session controller built over the Idle state and its startFreshPhrase action, the audio transport (queueBacking(phraseNumber, harmony, tempo), its click plan a piecewise tempo map with a new tempo segment from the first beat of each phrase queued at a new tempo, the count-in and phrase 1 at the starting tempo, and phraseStartsAt(phraseNumber) known up to the phrase after the last one queued), the session browser ports (wake lock, orientation lock, page visibility, window shape), the runner factory, the session clock (a wake-up timer factory, a wall clock and a frame loop), the idle layout gate's port, the measurement of phrase 1's staff fixed parts a loader of the engraver's staff planner (loadSessionStaffFitPlanner, beside that measurement), which the session's fit checks use, the player's saved session options (savedSessionOptions), which the three flags start from, the hold of the player's saves (saveHold: hold() at each accepted start, release() once at its teardown, and saveSession(changes, pageGoingAway), the session's own save at an end with a review), and the kept sessions as the load gave them (keptSessions: the kept summaries with their keys, the read of one kept session by its key, whether saving is off now, whether the visit started from the defaults, the changes to a kept session after its save and the request for persistent storage). The controller exposes readonly state (its phase: idle, count-in or running; the count-in display; the struggling notice; sessionTempo, the exact tempo in effect (the starting tempo during the count-in, then the tempo of the phrase sounding now, from its phrase-sounding output's tempo), null outside a session; adaptiveTempo, the page's flag, from the player's saved choice and then in memory for the page's lifetime; adaptiveTempoAvailable, true exactly while a controller is attached; varySettings, the page's vary-settings flag, and tensionAcrossPhrases, the page's tension-across-phrases flag, each from the player's saved choice and then in memory for the page's lifetime; shownSettings, the settings the read-only controls show during a session (its start settings during the count-in, then those the phrase now sounding was generated with), null outside a session; the held staff layout; canStart and the first start blocker; the staff the session shows and the highest phrase number it has readied, both null outside a session; the last end's summary and closed history; the review, the session it draws (its history, its instrument's name, tempoReached, the last sounded phrase's tempo, and how it is kept: pinned, not pinned or not saved) and whether it shows, or null when none exists; mostRecent, the most recent session, held in memory or kept on the device under its key, which a start leaves in place, or null when none exists; the starting note and its wait for the page's first click, tap or key press, the lost-controller countdown, the acknowledged notes and whether the session has a controller (module_session_starting_note, module_session_controller_loss, module_session_note_acknowledgement); lastSessionReachedTempo, the tempo the last session that ran adaptive tempo reached, or null before any such session, after an end of a session that did not run it, and after a reload), a query telling whether a phrase is on screen, and these actions: start (synchronous, for the Start click; throws while a start condition does not hold); stop (throws with no session running); the review mode's moves (module_kept_session_reach): closeReview (leaves the review mode from a review or the session list, the review kept, a pending opening cancelled; throws unless one of them shows), showReview (shows the most recent session's review, at once when it is held in memory and after reading it by its key when it is kept on the device, resolving a SessionOpening: 'shown'; 'failed' when the read does not give it, the session list showing instead with that session's row marked as failed to open; or 'superseded' when a session started or the most recent session changed meanwhile; throws unless a most recent session exists, neither a review nor the list shows, no session runs and no read is under way), openSession(key) (opens a kept session from its row, at Idle only, resolving a SessionOpening, the latest opening winning) and showList() (shows the session list, at Idle only, a review kept without showing); the changes to kept sessions (module_kept_session_changes, module_kept_session_reach): setKeepPlayedNotes(on), deletePlayedNotes(), deleteEveryKeptPlayedNote(), setFavorite(key, phraseNumber, favorite), setPinned(key, pinned), setComment(key, comment) and deleteSession(key), each at Idle only; setAdaptiveTempo(on) (throws during the count-in or a running session, and when turning the flag on while no controller is attached; turning it off at Idle always succeeds); setVarySettings(on) and setTensionAcrossPhrases(on) (each throws during the count-in or a running session); and dispose (ends a running session, stops reading the window and frees the wake-up timer). The runner's module is loaded by the workspace session's loadSessionRunner(), which createSessionController() calls as part of the controller's load.

## EXPECTATION
Building the session controller requests no lock and opens no audio; no session can start before its chunk has loaded. The session runner is not in the entry chunk. The three session options start from the player's saved choices. Between an accepted start and that session's teardown the player's saves are held, and the teardown releases them once.
