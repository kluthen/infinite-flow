# Infinite Flow First-Release Scope

## INTENT
Define the first-release scope as client-side generation of a short, legible musical phrase for a selected supported instrument profile under player-selected musical controls.

## THE RULE / LOGIC
The required release is a browser-based tool that generates and notates one four-measure musical proposal for a selected C MIDI keyboard, B-flat tenor saxophone, or E-flat alto saxophone profile. It excludes lead-line playback, required backing, microphone or acoustic-pitch processing, continuous or adaptive generation, persistence, performance scoring, and the listed future extensions.

## TECHNICAL INTERFACE
The release accepts a selected supported instrument profile, player-selected musical controls, an explicit regeneration action, optional MIDI connection feedback, and notation display-mode selection.

## EXPECTATION
Scope decisions keep the required release focused on selected-profile phrase generation and notation. Features outside the stated scope are not treated as required behavior until separately decided.
