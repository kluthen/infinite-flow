# Infinite Flow First-Release Scope

## INTENT
Establish Infinite Flow's first release as a browser-based, client-side practice partner for a monophonic musician, scoped to selected-profile phrase generation and notation rather than a MIDI-input, evaluative, or continuously adaptive tool.

## THE RULE / LOGIC
Infinite Flow proposes a harmonic context and a playable melodic response as one four-measure staff-notated phrase for a selected C MIDI keyboard, B-flat tenor saxophone, or E-flat alto saxophone profile, under player-selected musical controls that the player explicitly regenerates to hear a new variation. The required first release excludes MIDI controller connection, input, match or mismatch feedback, timing evaluation, MIDI-seeded continuation, generated lead-line playback, required backing or accompaniment, microphone capture or acoustic pitch detection, continuous or long-term-adaptive generation, session persistence, and performance scoring. Minimal MIDI connection and non-evaluative match or mismatch feedback are deferred to the immediate post-first-release roadmap item; that later scope must not display unmatched incoming pitches, evaluate timing, score the player, change generation, or advance the phrase.

## TECHNICAL INTERFACE
The first release accepts a selected supported instrument profile, player-selected musical controls, an explicit regeneration action, and notation display-mode selection. It exposes no MIDI-controller connection or input-feedback interface.

## EXPECTATION
Scope decisions keep the required release focused on a non-evaluative selected-profile phrase-generation practice partner without MIDI input. The deferred immediate post-release MIDI scope remains non-evaluative and does not alter phrase generation or progression.
