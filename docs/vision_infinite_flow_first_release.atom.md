# Infinite Flow First-Release Scope

## INTENT
Establish Infinite Flow's first release as a browser-based, client-side practice partner for a monophonic musician, scoped to selected-profile phrase generation and notation rather than an evaluative or continuously adaptive tool.

## THE RULE / LOGIC
Infinite Flow proposes a harmonic context and a playable melodic response as one four-measure staff-notated phrase for a selected C MIDI keyboard, B-flat tenor saxophone, or E-flat alto saxophone profile, under player-selected musical controls that the player explicitly regenerates to hear a new variation. The experience is collaborative rather than evaluative: it assigns no performance score, and any optional MIDI connection feedback stays a gentle match-or-mismatch indication rather than a timing or pitch evaluator. The required first release excludes generated lead-line playback, required backing or accompaniment, microphone capture or acoustic pitch detection, continuous or long-term-adaptive generation, session persistence, and performance scoring.

## TECHNICAL INTERFACE
The release accepts a selected supported instrument profile, player-selected musical controls, an explicit regeneration action, optional MIDI connection feedback, and notation display-mode selection.

## EXPECTATION
Scope decisions keep the required release focused on being a non-evaluative, selected-profile phrase-generation practice partner. Features outside this stated scope, including generated playback, required backing, microphone-based pitch detection, session persistence, and performance scoring, are not treated as required behavior until separately decided.
