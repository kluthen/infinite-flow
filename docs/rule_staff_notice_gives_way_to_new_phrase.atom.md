# Staff Notice Gives Way Only to a New Phrase

## INTENT
Make the "staff needs more room" notice clear only into a freshly generated phrase, never back into an old one.

## THE RULE / LOGIC
The notice gives way only to a new phrase or, under unsupported rhythm settings, to no phrase; never to a phrase shown before, and never to a phrase too dense to fit. When the notice shows because there is no room for the staff, it clears by itself once the staff fits: the phrase last on screen is not drawn again, and a new phrase is generated with the same round of up to three fresh-seed retries used to replace a phrase too dense for the staff. If every attempt of that round is too dense to fit, the notice shows again, now with the too-dense cause. While the window has no room for the staff, a phrase generated by hand cannot be shown either, so the notice stays.

## TECHNICAL INTERFACE
Clearing the notice triggers generation of a new phrase rather than a redraw of the previous one.

## EXPECTATION
- Once the staff fits again, the phrase last on screen is never redrawn; a new phrase is generated and shown if one of its attempts fits.
- If none fits, the notice returns with the too-dense cause.
- The notice never gives way to a phrase shown before it appeared.
